## 編集

1. HTMLをChromeまたはEdgeで開く。
2. 「文字を修正」で図の文字をクリック。Enterで確定。
3. 「配置を編集」で建物・説明枠・注意書きをドラッグ。工程の建物は道・矢印・看板も追従。
4. 「編集済みHTMLを保存」。SVG・PNGも別途保存可能。
5. Notionの元ページや添付は自動更新されない。必要なら手動で差し替え。

文字量を増やす場合、枠の外へのはみ出しに注意。移動後も重なりや交差は目視確認する。

## 解釈の範囲

- この図は設計の進め方であり、データ転送のシステム構成図ではない。
- 工程間の看板は引き継ぐ設計情報を要約したもの。下段の枠は工程ではなく補足。
- 正本の物理的保管先・配布先は参照ページに記載がないため「検討中」。
- OKS02／OKS07／OKS10の粒度・反映関係・単位・更新仕様は問いとして扱い、未確定のままとした。
- 4つのfact型、dimensionの履歴方針、物理設計・ロード・品質の要点を掲載。
- 23問すべての詳細、型変換やセキュリティの具体仕様は参照ページを確認する。
