# 進め方＆タスク

## 工数出力データの取込調査

### 取込方式の比較

[事前準備タスク｜工数データ取込方式の比較](ingestion-method-comparison.md)

#### 案1：月単位の洗い替え（達磨方式）

- 当月のデータをすべて洗い替える。
- 月パーティションが利用できると、運用しやすくなる見込み。
- Silverもテーブル更新とする。
- 構成がシンプル。

#### 案2：DataSpiderで最新テーブルのみを取得

- DataSpiderで日付ごとにグルーピングした最新テーブルを取得する。
- 全レコードをBronzeに保持し、Silverで処理する。
- 案1と比べて構成が複雑。

#### 確認事項

- 工数出力データに適した取込方式を決定する。
- 他テーブルの更新方式は、毎月のデータ件数を踏まえ、テーブル更新方式も含めて検討する。

### BigQueryの検討事項

- クラスタリングの適用を検討する。
- 統合キーのメリット・デメリットを整理し、連番方式と複合キーを比較する。
- ユースケースごとに集約階層（集約レベル）が異なるため、必要なデータ粒度を確認する。
- Bronzeで0行のデータを除外するか検討する。
- Silverで集約する場合に、実現できること・できないことを整理する。
- 各ページに付けたコメントの確認
