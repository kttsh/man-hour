# 進め方＆タスク

## 工数出力データの取込調査

### 取込方式の比較

工数データ出力を、単断面の入れ替え（案1）と差分の積み上げ（案2）のどちらで作るかを決める。

- 案の定義・判断ルール：[事前準備タスク｜工数データ取込方式の比較](ingestion-method-comparison.md)
- 測り方：[更新方式シミュレーションの要求事項](update-method-simulation-requirements.md)
- 他テーブルの更新方式は、毎月のデータ件数を踏まえ、テーブル更新方式も含めて検討する。

### BigQueryの検討事項

| 検討事項 | 状況 |
| --- | --- |
| クラスタリングの適用 | Bronzeは当初なし。取込方式の確定後に判断する |
| 統合キーの整理（連番方式と複合キーの比較） | Silverはハッシュ値のサロゲートキーに決定。実装の詳細はS-01 |
| ユースケースごとの集約階層と必要な粒度 | Silverは入力明細1件の粒度に決定。集約階層は未整理 |
| Bronzeで0時間の行を除外するか | 除外しないに決定（Bronze concept） |
| Silverで集約する場合にできること・できないこと | Silverでは集約しない方針。Gold以降で扱う |
| 各ページに付けたコメントの確認 | 未確認 |
